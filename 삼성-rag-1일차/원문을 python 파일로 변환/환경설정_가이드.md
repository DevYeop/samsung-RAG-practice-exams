# no-comments 실습 환경 설정 가이드

이 문서는 Windows에서 `no-comments` 실습을 처음 실행하는 분을 위한 안내입니다. Python 환경은 기존 실습 환경과 같은 **CPython 3.11.9**로 고정합니다.

## 준비물

- Windows 10 이상
- Python 3.11.9
- Ollama
- 모델과 패키지를 내려받을 인터넷 연결
- 약 15GB 이상의 여유 공간 권장

Python 3.11.9 다운로드: <https://www.python.org/downloads/release/python-3119/>

설치 화면에서 `Add python.exe to PATH`와 Python Launcher를 선택하세요.

Ollama 다운로드: <https://ollama.com/download/windows>

Ollama 설치 후 Windows 시작 메뉴에서 Ollama를 한 번 실행하세요. Ollama는 기본적으로 `http://localhost:11434`에서 실행됩니다.

## 가장 쉬운 방법: 자동 설정

PowerShell에서 `no-comments` 폴더로 이동합니다.

```powershell
cd "프로젝트경로\삼성-rag-1일차\no-comments"
Set-ExecutionPolicy -Scope Process Bypass
.\setup-windows.ps1
```

자동 설정 스크립트가 다음 작업을 순서대로 처리합니다.

1. Python 버전이 정확히 3.11.9인지 확인
2. `.venv311` 가상환경이 없으면 생성하고, 있으면 정상 환경인지 확인한 후 재사용
3. `requirements.txt` 패키지 설치 및 의존성 검사
4. 프로젝트 루트 `.env`가 없으면 루트 `.env.example`을 복사해 생성
5. Ollama의 `llama3.1`, `nomic-embed-text` 설치 여부 확인 후 없는 모델만 다운로드
6. `BAAI/bge-reranker-v2-m3`가 없으면 Hugging Face에서 다운로드

Hugging Face reranker 모델을 나중에 받고 싶다면 다음처럼 실행합니다.

```powershell
.\setup-windows.ps1 -SkipHuggingFaceModel
```

## API 키 입력

자동 설정 스크립트는 프로젝트 최상위에 `.env` 파일을 자동으로 만듭니다. 수동 설치를 선택했다면 프로젝트 루트에서 먼저 아래 명령을 실행합니다.

```powershell
cd "프로젝트경로"
Copy-Item .env.example .env
```

그 다음 프로젝트 최상위의 `.env` 파일을 메모장이나 VS Code로 열어 본인의 키를 입력합니다.

```dotenv
TAVILY_API_KEY=본인의_Tavily_API_키
OPENAI_API_KEY=본인의_OpenAI_API_키
NEO4J_URI=bolt://localhost:7687
NEO4J_USERNAME=neo4j
NEO4J_PASSWORD=본인의_Neo4j_비밀번호
```

- 실습 1-3, 1-4, 3-1: `TAVILY_API_KEY` 필요
- 실습 3-2 GraphRAG: `OPENAI_API_KEY` 필요
- 실습 3-2는 최초 실행 시 NIA PDF를 내려받으므로 인터넷 연결이 필요합니다. 이미 정상 파일이 있으면 다시 받지 않습니다.
- Neo4j 세 값은 선택 사항입니다. 비워 두면 GraphRAG가 인메모리 그래프를 사용합니다.
- 실제 루트 `.env`는 루트 `.gitignore`에 등록되어 GitHub에 올라가지 않습니다.
- 루트 `.env.example`에는 예시 값만 넣고 공개 저장소에 함께 올립니다.

## GitHub 공개 전 보안 확인

프로젝트 루트에서 실제 API 키가 소스에 들어 있지 않은지 확인합니다.

```powershell
cd "프로젝트경로"
git grep -n -E "(sk-|tvly-)"
git status --short
```

첫 명령은 아무것도 출력되지 않아야 합니다. 루트 `.env`가 `git status`에 나타나면 공개하기 전에 루트 `.gitignore` 내용을 다시 확인하세요.

이미 Git이 추적 중인 캐시가 있는지도 확인합니다.

```powershell
git ls-files | Select-String -Pattern '(^|/)(\.env|\.venv311/|__pycache__/|vectorstore/)'
```

출력이 있다면 해당 파일은 `.gitignore`를 추가하기 전에 추적된 것입니다. 필요한 데이터인지 먼저 확인한 뒤 Git 추적 대상에서 제외해야 합니다.

기존 코드에 한 번이라도 실제 키를 저장하거나 커밋했다면 해당 키를 폐기하고 서비스에서 새 키를 발급받아야 합니다. 파일에서 문자열만 지워도 Git 기록에는 남을 수 있습니다.

## 자주 발생하는 오류

### `py`를 찾을 수 없음

Python 3.11.9를 다시 설치하면서 Python Launcher를 포함하세요.

### PowerShell에서 스크립트를 실행할 수 없음

현재 PowerShell 창에서만 실행 정책을 완화합니다.

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

### Ollama에 연결할 수 없음

Windows 시작 메뉴에서 Ollama를 실행한 다음 확인합니다.

```powershell
ollama list
```

### API 키 오류

`.env.example`이 아니라 `.env` 파일에 값을 입력했는지 확인하세요. 값 양쪽에 불필요한 따옴표나 공백을 넣지 않는 것이 좋습니다.
